Get Hello Bebe

On a Moto G, in about two minutes.

Download Hello Bebe

Open this page on the phone itself. About 115 MB, so Wi-Fi is best.

  1. Download it

    Tap the pink button above. If Chrome says the file might be harmful, tap Download anyway. It's only Hello Bebe.

  2. Open the file

    When it finishes, tap Open. Missed it? Open the Files app, go to Downloads and tap HelloBebe.apk.

  3. Let Chrome install apps

    The first time, the phone says it can't install apps from this source. Tap Settings, switch on Allow from this source, then go back.

  4. Install

    Tap Install. If Play Protect pops up, tap More details, then Install anyway. It warns about any app that isn't from the Play Store.

  5. Play

    Tap Open, or find Bebe on your home screen. Turn the phone sideways.

New versions

When there's an update, the title screen shows a button for it. Tap it, then do steps 2 and 4 again. Your party in progress is kept.

If the phone ever says the app conflicts with an existing one, don't uninstall without asking first: that would lose the saved party.
